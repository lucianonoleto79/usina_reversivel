# Instruções para o Claude

## GitHub: só quando solicitado
- **Não fazer push** (upload para o GitHub) sem pedido explícito do usuário.
  Commits locais são permitidos; o push só acontece quando solicitado.
- **Não abrir pull requests** sem pedido explícito do usuário.
- **Não fazer merge** (de PR ou de branches) sem pedido explícito do usuário.
- A autorização vale apenas para a ação pedida naquele momento; não se estende
  a pushes, PRs ou merges seguintes.
